# R2 loss 消融结果

运行时间：2026-07-31  
统一协议：Tiny-SimVP、递归 10→10→10、5 epoch、seed 0。

## 实验定义

| 实验 | Huber | 强像素加权 | Soft CSI |
|---|---|---|---|
| R2a | 是 | 否 | 否 |
| R2b | 是 | 16/32 增量 2/3 | 否 |
| R2c | 是 | 16/32 增量 2/3 | 全 batch、全 20 帧 micro |
| R2d | 是 | 16/32 增量 2/3 | 样本 × 0–1h/1–2h 分段 |

R2c 日志中的 `train_soft_csi_weighted / train_huber` 从 9.7% 上升到
17.3%，说明 Soft CSI 已有实质影响，但没有压倒 Huber。

## 五轮最佳结果

| 实验 | 最佳 epoch | Val MSE best | CSI score best |
|---|---:|---:|---:|
| R1 MSE | 0 | 0.010082 | 0.331482 |
| R2a Huber | 4 | 0.011110 | 0.381217 |
| R2b Weighted Huber | 4 | 0.011260 | 0.531419 |
| R2c micro Soft CSI | 0 | 0.011229 | **0.609635** |
| R2d segmented Soft CSI | 1 | 0.011330 | 0.604806 |

Val MSE best 和 CSI best 可能来自不同 epoch；表中 epoch 指 CSI best。

消融结论：

1. Huber 相对 MSE 只有小幅收益；
2. 强像素加权将最佳 CSI 从 0.381 提升到 0.531，是主要增益来源；
3. Soft CSI 进一步提升到约 0.61，具有独立价值；
4. 分段 Soft CSI 与 micro Soft CSI 总分基本持平，但误报更低、更适合作为后续基线。

这符合“递归第二段产生位置/形态误差”的判断，继续增加强度权重不太可能根治。

## R2d 实现

- Soft CSI 按 `样本 × 时段 × 阈值` 计算；
- 只对存在真实强降水的样本平均 CSI loss；
- 无强降水样本保留 0.1 倍 soft false-positive penalty；
- 四项相对权重为 1.0/0.5/1.2/0.6，总量保持约 0.006；
- CSI checkpoint 保存 top-3；
- 新增 `--skip_test_after_train`，避免训练后隐式测试 Last。

## 决策

建议将 R2d 作为进入 R3 的 loss 基线，而不是继续大范围搜索 loss 权重。
R2d 已修正时效结构，并以几乎相同的 CSI score 换取更低 FAR；剩余主要问题集中在
第二小时的 Bias、POD 和位置重叠，应由直接 10→20 的 R3 验证。
