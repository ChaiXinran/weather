# R3 direct 10→20：5-epoch 结果

运行时间：2026-07-31  
实验目录：`work_dirs/bth_simvp_gsta_r3_direct_5ep_seed0`  
R3 日志：`lightning_logs/version_17/metrics.csv`  
R2d 逐 lead 复评日志：`lightning_logs/version_19/metrics.csv`

## 受控修改

R3 固定 R2d loss、数据、seed、学习率、OneCycle、batch size 和 Tiny-SimVP
主干，只修改输出机制：

```text
R2d: X[-9:0] → f → Xhat[1:10] → f → Xhat[11:20]
R3:  X[-9:0] → encoder/translator → learned 10→20 projections → Xhat[1:20]
```

主 latent 和 encoder skip 分别使用一个 1×1 时间投影，从 `10·C_h` 映射到
`20·C_h`，不是复制或插值。

R3 恢复了第二小时覆盖和强度，尤其 Bias@32，但 FAR 同时上升；第二小时
CSI@32 改善，CSI@16 反而下降。因此它不是全面胜出，而是更偏向恢复覆盖。

第一小时没有退化，两个阈值分别提高 0.034 和 0.041，满足内部
`ΔCSI(0–1h) ≥ -0.005` 标准。

递归 R2d 在边界处确有 Bias32 和强度下降，但 CSI 并不存在特别尖锐的断崖；
衰减在 +60 分钟之前已经持续发生。R3 消除了边界处的覆盖/强度下降，却没有消除
CSI/FAR 恶化，说明剩余误差不只是第二次递归调用，还包括长时效空间定位能力。

## 结论

R3 是正向结构实验：总分、第一小时、第二小时覆盖、Intensity Ratio 和
CSI@32 均改善，且训练更快。它验证了直接 10→20 值得作为后续主线。

但“递归边界是唯一瓶颈”的强假设不成立：第二小时 CSI@16 与 FAR 没有改善，
逐 lead 曲线也显示误差是连续积累而非只在 +60→+66 分钟突变。

建议下一步对 R3 做 10–15 epoch、至少 3 个 seed，并对 CSI top-3 运行完整空间
评价；暂不加入 PWV 或扩大主干。
